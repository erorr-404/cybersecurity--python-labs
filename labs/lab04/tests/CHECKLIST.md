
# Чек-лист впровадження тестів

## Оцінка (`decision`)

- [x] Оцінка нижче порога
- [x] Оцінка на порозі
- [x] Оцінка вище порога
- [x] невідповідна ознака за високої оцінки

## Запис

- [x] Запис не знайдено
- [x] Запис відхилено (`rejected`)
- [x] Оцінка або потрібне поле відсутні
- [x] Некоректний тип чи значення потрібного поля має спричиняти помилку

## Metric

- [x] Перша оцінка `Primary` має пріоритет над попередньою `Secondary`
- [x] За відсутності `Primary` обирається перша оцінка

## Requests

- [x] Успішний запит
- [x] HTTP помилка
- [x] Мережева помилка
- [x] Перевірка заголовків з ключем
- [x] Перевірка заголовків без ключа

## Локальний запуск

- [x] Локальний запуск із JSON-файлом формує звіт і не звертається до мережі
- [x] Некоректний JSON завершує програму з повідомленням про помилку
- [x] Відсутній файл також
